# To-Do List

A simple To-Do List web app built using **HTML, CSS, and JavaScript**.

🔗 Live Demo: https://satvikadev.github.io/to-do-list/

### Features

* Add tasks
* Complete tasks
* Delete tasks
* Simple UI

### Tech Used

* HTML
* CSS
* JavaScript

### Upcoming Features

* Save tasks using LocalStorage
* Edit tasks
* Keyboard support
* Responsive design
* Improved UI/UX

### How to Run

1. Clone the repository
2. Open `index.html`
3. Start adding tasks
